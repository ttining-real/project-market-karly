### 컨벤션

#### 1️⃣ 깃 컨벤션

- Issut labels
- Git Branch
  ```bash
  # 기능/영역/이름
  feature/detail/kim # 예) kim이 디테일 페이지를 만드는 브랜치
  ```

- Git Commit
  ```bash
  🎨 label: title
  - text
  
  # 예시
  💙 Component: 모달창 생성 후 템플릿에 적용
  - template.html
  ```

<br>

#### 2️⃣ 코드 컨벤션

- 네이밍 규칙
  - `class` : BEM 방식 (`block__element--modifier`)
  - 변수, 함수 - `camelCase` 방식

<br>

#### 3️⃣ 아토믹 디자인 시스템

- Atoms > Molecules > Organisms > Template > pages
