### 컨벤션

① 깃 컨벤션

- Issut labels

- Git Branch

```
기능/영역/해당개발자이름
예) kim 이 디테일페이지를 만드는 브랜치 : feature/detail/kim
```

- Git Commit

```
🎨 label: title
- text
예) 💙 Component: 모달창 생성 후 템플릿에 적용
- template.html
```

② 코드 컨벤션

- 네이밍 규칙
  - class : BEM 방식 (blodk\_\_element--modifier)
  - 변수, 함수 - camelCase 방식

③ 아토믹 디자인 시스템

- Atoms > Molecules > Organisms > Template > pages
